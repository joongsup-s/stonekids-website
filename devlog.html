사내 리뷰 시스템

시놀로지 NAS 기반 영상 리뷰·어노테이션 도구

Frame.io도 Vimeo도 있지만, 매번 업로드하고 링크를 공유하고 리뷰어가 로그인하는 과정이 번거로웠습니다 — 새 버전을 렌더할 때마다요. 그래서 우리 나스를 서버로 삼아, 폴더를 통째로 스캔·인덱싱해 데이터베이스로 관리하고, 영상 위에 바로 그려 리뷰하는 시스템을 직접 만들었습니다. 회사에 최적화된 도구로 협업 생산성을 높이고, 그만큼 콘텐츠의 질로 되돌리기 위해서요.

  • NAS 폴더 스캔·인덱싱 → 업로드 없이 그 자리에서 리뷰
  • 프레임 위 드로잉(펜·화살표·사각형·포스트잇) + 타임코드·구간 코멘트
  • 실시간 협업(SSE) · 버전 관리 · 리뷰 링크 공유
  • Docker 컨테이너로 패키징 — 시놀로지 위에서 구동

AI 사회자 비주얼 (음성 반응)

AI 진행자의 목소리에 실시간 반응하는 무대 LED 비주얼

행사의 사회·나레이션을 AI가 맡았을 때, 목소리뿐인 그 AI에게 무대 위 ‘얼굴’을 만들어 주기 위해 직접 개발했습니다. AI 나레이션의 음성 주파수 스펙트럼에 맞춰 스파클과 성운이 피어나고 잦아듭니다. 구글 Gemini 디자인 언어의 무드로 설계했고, 1920×1080 규격으로 송출합니다.

  • 마이크 입력 → 음성 주파수 스펙트럼 실시간 반응
  • Gemini 스파클(4각별) + 성운 파티클, 부드러운 보간(lerp) 모션
  • 화이트/블랙 테마 · 마이크 선택 · 전체화면 · 1920×1080 송출
  • 오프라인 단독 실행(.app) — 현장 네트워크와 무관하게 구동

겟로고 (GetLogo)

getlogo.kr · 관공서·공공기관·기업 로고 허브

기관 로고 하나 찾으려고 수십 개 홈페이지를 헤매던 경험에서 출발했습니다. 중앙정부·지방자치단체·공공기관에 대학·지방공기업·출자출연기관, 그리고 주요 기업까지 937곳의 상징(CI/BI)·로고를 한 곳에 모았습니다. 원본은 직접 호스팅하지 않고 공식 출처로 바로 연결하는 링크 허브입니다.

  • 기관명·초성 검색 + 분류·세부분류·지역·포맷 필터
  • 브랜드 대표 컬러 추출 — HEX·RGB·HSL·CMYK 원클릭 복사
  • 회원·팀 단위 로고 컬렉션(개인·팀 프라이빗 자산) 관리
  • 로고 자동 수집·정규화·검증 파이프라인 + 품질 자동 감사
  • 누락 기관 제보·등록 시스템(소유·관리권 확인)
  • SEO/AEO 최적화 — "○○시 로고" 검색 대응

NDI 방송 그래픽 송출기

라이브 방송·스트리밍 그래픽 송출 도구 (내부 프로덕션용)

라이브 방송·스트리밍 현장에서 자막·로고·하단띠·점수판·타이머 같은 그래픽을 카드 단위로 큐잉해, 알파 채널 포함 NDI로 송출하는 도구입니다. OBS·vMix와 바로 결합합니다. 오픈소스 에디터(OpenCut) 포크를 먼저 시도했으나 한계에 부딪혀, 지금은 자체 엔진으로 처음부터 개발 중입니다.

  • 자막·하단띠·점수판·타이머를 카드로 큐잉/송출
  • 알파 포함 NDI 송출(Program) + 앱 내 Preview 격리
  • OBS·vMix 연동, 1인 운영 워크플로
  • 오픈소스 포크 → 자체 그래픽 엔진 직접 개발로 전환
