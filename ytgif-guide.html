YTgif

쓰는 법은 셋 — 넣고, 자르고, 만든다.

유튜브 링크를 붙여넣고, 타임라인에서 원하는 구간을 잡고, 버튼 하나로 GIF로 뽑습니다. 위에서 아래로 ① 소스 → ② 구간 → ③ 모양 → 만들기, 한 화면에서 끝납니다.

붙여넣기 자동 로드프레임 단위 구간확대되는 타임라인원클릭 변환DMG 설치
← YTgif 소개로 돌아가기

한 화면에 다 들어옵니다 — 스크롤 없이 ① 소스 · ② 구간 · ③ 모양 · 만들기

먼저, 설치

  1. YTgif.dmg를 열고 YTgif 앱을 Applications 폴더로 끌어다 놓습니다.
  2. 처음 한 번은 미서명 앱 경고가 뜹니다. 터미널에 아래 한 줄을 붙여넣어 격리를 풀어줍니다(동봉된 변환 도구까지 함께 해제됩니다). xattr -dr com.apple.quarantine /Applications/YTgif.app
  3. 이제 더블클릭으로 실행하면 됩니다. 이후엔 경고 없이 바로 열립니다.

변환 엔진(ffmpeg)과 유튜브 다운로더(yt-dlp)는 앱에 내장되어 있어 따로 설치할 필요가 없습니다. 단, macOS 기본 명령어 도구(python3)는 필요합니다 — 대부분의 맥에 이미 있고, 없으면 첫 실행 때 설치 안내가 한 번 뜹니다.

How to use

3단계, 그리고 만들기

STEP 01

소스 넣기 — 붙여넣으면 끝

유튜브 주소를 입력칸에 붙여넣기(⌘V)만 하면 바로 로드됩니다. 불러오기 버튼을 누를 필요도 없습니다. 손에 있는 영상 파일은 앱 화면 어디에든 끌어다 놓으면 전면 오버레이로 받아주고, "파일 열기"로 직접 골라도 됩니다.

  • 링크 붙여넣기 → 자동 파싱·로드 (불러오기 클릭 불필요)
  • 영상 파일 전체 화면 드래그 & 드롭 · mp4·mov·mkv·webm·avi
  • 웹뷰가 막힌 영상은 "원본 받기"로 내려받아 그대로 미리보기·변환 (진행률 표시)
STEP 02

구간 잡기 — 어디인지 보면서, 정확히

트랙에 시간 눈금이 깔려 있고, IN/OUT 핸들마다 현재 시각이 버블로 붙어 어디를 잡았는지 한눈에 보입니다. 재생하다가 "시작/끝" 버튼으로 현재 위치를 찍거나, 핸들을 직접 끌면 됩니다. 1시간짜리 영상에서 2~3초를 뽑을 땐 "구간 확대"로 줌인 — 위쪽 미니맵이 전체 위치를, 아래 확대된 트랙이 정밀 조작을 맡습니다.

  • 핸들 드래그 · 트랙 클릭으로 탐색 · 시간 버블로 위치 확인
  • 편집 가능한 시작/끝 시간 필드 + 프레임 ±버튼으로 정밀 보정
  • ⌘+휠 확대/축소, 확대 중 가로 스와이프로 이동
  • 키보드: ←/→ 1프레임(Shift 10), I / O 현재 위치를 시작/끝점
STEP 03

모양 고르고 — 버튼 하나로

프리셋(Instagram·Discord·Telegram·카카오·직접 설정)을 고르면 해상도·FPS·색상이 한 번에 맞춰집니다. 예상 용량·변환 시간이 바로 옆에 뜨고, 더 손보고 싶으면 "세부 조정"에서 해상도·색상 수·디더링까지 만집니다. 그리고 "GIF 만들기" 한 번이면 추가와 변환이 끝 — 결과는 큐에서 확인합니다.

  • 프리셋 한 번으로 플랫폼별 권장값 적용 · 예상 용량/시간 표시
  • "GIF 만들기": 추가 + 변환을 한 번에 (원클릭)
  • 여러 개는 "목록에 담기" 후 큐 서랍에서 "대기열 전체 만들기"로 일괄

단축키

마우스 없이도 빠르게. 타임라인·플레이어에서 바로 통합니다.

⌘V링크 붙여넣기 → 자동 로드
I현재 재생 위치를 시작점으로
O현재 재생 위치를 끝점으로
← / →선택한 핸들 1프레임 이동
Shift + ← / →10프레임 이동
⌘(Ctrl) + 휠타임라인 확대 / 축소
가로 스와이프확대된 타임라인 좌우 이동
⌘V (붙여넣기)입력칸 밖에서도 링크면 자동 로드
  • 큐 서랍 — 우상단 "큐"를 누르면 만든 GIF·저장한 영상 목록이 옆에서 열립니다. 진행률·열기·폴더·삭제를 한곳에서.
  • 고급설정 — 저장 위치, 완료 후 동작(파일 열기 / 파인더에서 보기), 동시 작업 수·엔진, 완료 알림을 한 번에 설정합니다.
  • 다크/라이트 자동 — macOS 시스템 테마를 그대로 따라갑니다. 따로 설정할 게 없습니다.
  • 권리 있는 소재만 — 다운로드 기능은 본인 권리가 있는 영상(CC·사내·위탁 제작물 등)에만 쓰세요. 받은 파일의 사용 책임은 사용자에게 있습니다.
