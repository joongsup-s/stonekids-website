YTgif

유튜브의 그 장면, 한 칸의 GIF로.
그것도 내 손에 맞게.

유튜브 영상에서 보여주고 싶은 구간만 골라, 프레임 단위로 다듬어, 바로 GIF로 뽑는 데스크톱 도구입니다. 캔버스 위 협업에서 "말로 설명하지 말고 그냥 움직이는 걸 보여주자"는 생각에서 출발해, 개발자 심중섭이 자신의 작업 방식에 맞춰 처음부터 직접 만들었습니다.

YouTube → GIF프레임 단위 구간 선택배치 렌더 큐도킹 레이아웃로컬 파일 지원

한 화면에서 끝납니다 — 불러오기 · 구간 선택 · 옵션 · 큐 적재 · 배치 렌더링

왜 만들었나 — "이미지로는 부족했다"

스톤키즈의 협업은 allo.io 무한 캔버스 위에서 이뤄집니다. 레퍼런스를 붙이고, 편집 방향을 논의하고, "이 느낌"을 공유하는 자리죠. 그런데 캔버스에 정지 이미지 한 장을 올려두면 늘 같은 한계에 부딪혔습니다 — 움직임은 말로 풀어 써야 했고, 받는 사람은 그 말을 머릿속에서 다시 영상으로 되돌려야 했습니다.

심중섭은 단순한 판단을 내렸습니다. "캔버스 위 소통에는 이미지보다 GIF가 낫다." 짧게 반복 재생되는 한 칸의 움직임은, 긴 설명문보다 빠르고 정확하게 의도를 전달했으니까요. 유튜브 레퍼런스의 바로 그 3초를, 클릭 몇 번으로 캔버스에 얹을 수 있다면.

"내가 쓰기 편한 방식이 곧 사양서였다. 남이 만든 GIF 변환기를 참는 대신, 내 손에 맞는 도구를 직접 만들기로 했다."

시중의 GIF 변환기는 대개 한 번에 하나씩, 웹 업로드와 광고를 거쳐, 원하는 옵션은 반쯤만 줬습니다. YTgif는 그 반대로 설계했습니다. 로컬에서 빠르게, 프레임 단위로 정확하게, 여러 개를 큐에 쌓아 한 번에. 철저히 한 사람의 실제 작업 동선에 맞춰 다듬은, 그래서 군더더기가 없는 도구입니다.

What it does

기능 하나하나가, 실제로 쓰던 동선입니다

01

유튜브 URL을 붙이면, 웹뷰로 바로 재생

주소만 붙여 넣으면 유튜브 웹뷰 플레이어가 곧장 열립니다. 영상을 보면서 원하는 지점에서 IN 설정 · OUT 설정을 누르면 그 자리가 구간이 됩니다. 별도의 다운로드 앱도, 화면 녹화도 필요 없습니다.

  • 유튜브 재생바 그대로 — 익숙한 방식으로 위치 탐색
  • 현재 재생 위치를 한 번에 IN/OUT으로 지정
  • 임베드가 막힌 영상은 "다운로드 후 진행"으로 우회
02

프레임 단위로 정확하게 잘라낸다

"대충 3초쯤"이 아니라, 정확히 그 프레임에서 시작하고 끝납니다. START·END를 직접 입력하거나 −10f / −1f / +1f / +10f 버튼으로 미세 조정하면, 선택 구간의 길이와 프레임 수가 실시간으로 표시됩니다.

  • 소스 영상의 실제 FPS 기준으로 프레임 스냅
  • F0 – F75 처럼 프레임 범위와 길이를 즉시 확인
  • Loop Preview로 잘라낸 구간만 반복 재생해 검수
03

화질은 타협하지 않는다

해상도·FPS·색상 수·품질·반복·재생 방향(정방향/역방향/핑퐁)까지 손에 잡힙니다. 팔레트는 프레임 전체 기준(full)으로 뽑고 sierra2_4a 오차확산 디더링을 써서, 같은 GIF여도 원본 색감에 훨씬 가깝게 — 띠 무늬(밴딩) 없이 매끈하게 나옵니다.

  • 인스타·디스코드·텔레그램·카카오·트위터 프리셋
  • 예상 파일 크기·렌더 시간을 미리 가늠
  • 플랫폼별 용량 한도에 맞춰 색상 수만 낮춰도 깔끔
04

여러 개를 쌓아, 한 번에 굽는다

장면 하나 고를 때마다 변환을 기다리지 않습니다. 만들 GIF를 큐에 차곡차곡 쌓아 두고 배치 렌더링을 돌리면 알아서 처리합니다. 각 작업의 썸네일·구간·설정·진행률·예상 용량이 한눈에 보이고, 완료된 건 열기·폴더로 바로 확인합니다.

  • 드래그로 순서 변경, 실패 작업만 재시도
  • 완료 시 결과 GIF를 Finder에서 바로 열기
  • 작업 목록은 프로젝트로 저장·복구
05

로컬 파일도, 끌어다 놓기만

유튜브만이 아닙니다. 손에 있는 영상 파일을 드래그 & 드롭하면 그대로 소스가 됩니다. 업로드되는 즉시 썸네일을 만들어 보여주고, 같은 구간 선택·배치 렌더링 흐름을 똑같이 탑니다. 동시 작업 수와 출력 폴더까지, 내 장비에 맞게 설정합니다.

  • mp4·mov·mkv·webm·avi 등 폭넓은 포맷
  • 업로드 영상에서 대표 프레임 썸네일 자동 생성
  • 출력 폴더 지정 — 결과물을 내 폴더 구조에 정리
06

작업대는 내 마음대로 — 도킹 레이아웃

프리미어처럼, 패널 사이 경계선을 끌면 양옆이 함께 늘고 줄며 빈틈 없이 타일로 채워집니다. 패널 제목 줄을 끌어 다른 패널 가장자리에 놓으면 그쪽으로 도킹돼 배치가 바뀝니다. 미리보기를 크게, 큐를 넓게 — 그날 작업에 맞춰 화면을 짭니다. 배치는 저장되어 다음에도 그대로입니다.

  • 경계 스플리터로 패널 크기 동시 조절
  • 헤더 드래그 → 상·하·좌·우 도킹, 중앙 교환
  • 레이아웃 저장·복원, 메뉴에서 초기화
The output

설명 대신, 그냥 보여주면 됩니다

오른쪽은 YTgif로 뽑은 실제 결과물입니다. 캔버스에 이 한 칸을 얹는 순간, "여기서 이렇게 움직였으면 좋겠어요"라는 긴 문장은 필요 없어집니다.

full 팔레트 + 오차확산 디더링으로 만든 GIF는 색이 뭉개지지 않고, 작은 용량으로도 의도를 또렷이 전달합니다. 도구가 사람에게 맞춰질 때 일어나는 일입니다.

YTgif로 만든 실제 GIF · 360×202 · 12fps · 256색

필요는 내가 가장 잘 안다

YTgif는 거창한 제품이 아니라, 한 사람의 하루를 더 매끄럽게 만들려고 시작한 도구입니다. 현장에서 겪은 불편을 그냥 넘기지 않고, 내게 맞는 사용성으로 직접 풀어낸 결과 — 그게 스톤키즈 Lab이 일하는 방식입니다.

스톤키즈는 영상 프로덕션입니다.

여기 있는 도구들은 더 좋은 영상을 만들려다 직접 만든 결과물입니다. 촬영·편집·라이브 중계 등 영상 제작이 필요하시면 편하게 연락 주세요.
