YTgif

유튜브의 그 장면, 한 칸의 GIF로.
그것도 내 손에 맞게.

유튜브 영상에서 보여주고 싶은 구간만 골라, 프레임 단위로 다듬어, 바로 GIF로 뽑는 데스크톱 도구입니다. 캔버스 협업에서 "말로 설명하지 말고 그냥 움직이는 걸 보여주자"는 생각에서 출발해, 시중 도구에 맞추는 대신 실제 작업 방식에 딱 맞게 처음부터 직접 만들었습니다.

YouTube → GIF프레임 단위 구간 선택확대되는 타임라인렌더 + 다운로드 통합 큐영상·음원 다운로더다크/라이트 자동로컬 파일 지원

📖 사용법 가이드 보기 →

새 디자인 — 한 화면 컴팩트 · 붙여넣기 자동 로드 · 눈금·확대되는 타임라인 · 원클릭 GIF 만들기

왜 만들었나 — "이미지로는 부족했다"

스톤키즈는 협업의 많은 부분을 allo.io 위에서 합니다. 흩어진 초안과 레퍼런스, 피드백을 하나의 캔버스에 모아 나란히 두고, 함께 보며 결정하는 비주얼 협업 도구죠. 레퍼런스를 붙이고, 편집 방향을 논의하고, "이 느낌"을 맞춰가는 자리입니다.

그런데 캔버스에 정지 이미지 한 장을 올려두면 늘 같은 벽에 부딪혔습니다 — 움직임은 결국 말로 풀어 써야 했고, 받는 사람은 그 설명을 머릿속에서 다시 영상으로 되돌려야 했습니다. "여기서 이렇게 휙 지나가는 느낌"은 글로는 좀처럼 전해지지 않으니까요.

그래서 답은 단순했습니다. "캔버스 위 소통에는 이미지보다 GIF가 낫다." 짧게 반복되는 한 칸의 움직임은 긴 설명문보다 빠르고 정확하게 의도를 전합니다. 유튜브 레퍼런스의 바로 그 3초를 클릭 몇 번으로 캔버스에 얹을 수 있다면, 회의는 그만큼 짧아집니다.

"쓰기 편한 방식이 곧 사양서였다. 남이 만든 변환기에 나를 맞추는 대신, 내 손에 맞는 도구를 직접 만들기로 했다."

시중의 GIF 변환기는 대개 한 번에 하나씩, 웹 업로드와 광고를 거쳐, 정작 원하는 옵션은 반만 줬습니다. YTgif는 그 반대로 설계했습니다. 로컬에서 빠르게, 프레임 단위로 정확하게, 여러 개를 큐에 쌓아 한 번에. 실제 작업 동선을 그대로 본떠 다듬었기에, 군더더기가 없습니다.

What it does

기능 하나하나가, 실제로 쓰던 동선입니다

01

유튜브 URL을 붙이면, 웹뷰로 바로 재생

주소만 붙여 넣으면 유튜브 웹뷰 플레이어가 곧장 열립니다. 영상을 보면서 원하는 지점에서 IN 설정 · OUT 설정을 누르면 그 자리가 구간이 됩니다. 별도의 다운로드 앱도, 화면 녹화도 필요 없습니다.

  • 유튜브 재생바 그대로 — 익숙한 방식으로 위치 탐색
  • 현재 재생 위치를 한 번에 IN/OUT으로 지정
  • 임베드가 막힌 영상은 "다운로드 후 진행"으로 우회
02

긴 영상도, 2초 구간을 정확히 — 새 타임라인

트랙에 시간 눈금이 깔리고, IN/OUT 핸들마다 현재 시각이 버블로 붙어 어디를 잡았는지 한눈에 보입니다. 1시간짜리 영상에서 2~3초를 뽑을 땐 "구간 확대"로 줌인 — 위쪽 미니맵이 전체 위치를 알려주고, 아래 확대된 트랙에서 핸들을 편하게 끕니다. 정밀하게는 시간 입력 + 프레임 ±스텝, 키보드(←/→ 1프레임, I/O로 현재 위치 지정)까지.

  • 시간 눈금·현재 재생위치(playhead)·핸들 시간 버블
  • ⌘+휠 확대/축소, 확대 중 가로 스와이프로 이동
  • 편집 가능한 시작/끝 필드 + 프레임 단위 미세 조정
03

화질은 타협하지 않는다

해상도·FPS·색상 수·품질·반복·재생 방향(정방향/역방향/핑퐁)까지 손에 잡힙니다. 팔레트는 프레임 전체 기준(full)으로 뽑고 sierra2_4a 오차확산 디더링을 써서, 같은 GIF여도 원본 색감에 훨씬 가깝게 — 띠 무늬(밴딩) 없이 매끈하게 나옵니다.

  • 인스타·디스코드·텔레그램·카카오·트위터 프리셋
  • 예상 파일 크기·렌더 시간을 미리 가늠
  • 플랫폼별 용량 한도에 맞춰 색상 수만 낮춰도 깔끔
04

여러 개를 쌓아, 한 번에 굽는다

장면 하나 고를 때마다 변환을 기다리지 않습니다. 만들 GIF를 큐에 차곡차곡 쌓아 두고 배치 렌더링을 돌리면 알아서 처리합니다. 각 작업의 썸네일·구간·설정·진행률·예상 용량이 한눈에 보이고, 완료된 건 열기·폴더로 바로 확인합니다. 렌더 큐와 다운로드 큐는 한 패널에서 탭으로 오가며, 변환과 다운로드가 동시에 돌아갑니다.

  • 드래그로 순서 변경, 실패 작업만 재시도
  • 완료 시 결과 GIF를 Finder에서 바로 열기
  • 작업 목록은 프로젝트로 저장·복구
05

로컬 파일도, 끌어다 놓기만

유튜브만이 아닙니다. 손에 있는 영상 파일을 드래그 & 드롭하면 그대로 소스가 됩니다. 업로드되는 즉시 썸네일을 만들어 보여주고, 같은 구간 선택·배치 렌더링 흐름을 똑같이 탑니다. 동시 작업 수와 출력 폴더까지, 내 장비에 맞게 설정합니다.

  • mp4·mov·mkv·webm·avi 등 폭넓은 포맷
  • 업로드 영상에서 대표 프레임 썸네일 자동 생성
  • 출력 폴더 지정 — 결과물을 내 폴더 구조에 정리
06

한 화면에 딱 — 다크·컴팩트·원클릭

스크롤 없이 한 화면에 소스·구간·모양·만들기가 모두 들어옵니다. 시스템 테마를 따라 다크/라이트 자동. 링크는 붙여넣기만 하면 바로 로드되고, 영상 파일은 앱 어디에 끌어다 놔도 오버레이로 받습니다. 만들기는 버튼 하나 — "GIF 만들기"가 추가와 변환을 한 번에 끝내고, 여러 개는 "목록에 담기" 후 큐에서 일괄 처리합니다.

  • 무스크롤 컴팩트 레이아웃 · 다크/라이트 자동
  • 붙여넣기 자동 로드 + 전체 화면 드래그 & 드롭
  • 원클릭 변환, 차단 영상은 다운로드 진행률까지 표시
07

레퍼런스째 받아두고 싶을 땐, 다운로더

GIF로 자르기 전에 원본을 통째로 갖고 싶을 때가 있습니다. URL과 화질만 고르면 다운로드 큐에 들어가, 진행률·속도·남은 시간이 실시간으로 보이고 끝나면 Finder로 바로 열립니다. 화질 목록은 영상마다 실제로 받을 수 있는 해상도만 띄우고, 음원만 필요하면 MP3·M4A로 뽑습니다.

  • 원본~720p·음원(MP3/M4A) — 가용 옵션만 노출
  • 받는 중 진행률·속도·ETA, 취소·재시도
  • 임베드가 막힌 영상도 받아서 미리보기·변환까지
The output

설명 대신, 그냥 보여주면 됩니다

오른쪽은 YTgif로 뽑은 실제 결과물입니다. 캔버스에 이 한 칸을 얹는 순간, "여기서 이렇게 움직였으면 좋겠어요"라는 긴 문장은 필요 없어집니다.

full 팔레트 + 오차확산 디더링으로 만든 GIF는 색이 뭉개지지 않고, 작은 용량으로도 의도를 또렷이 전달합니다. 도구가 사람에게 맞춰질 때 일어나는 일입니다.

YTgif로 만든 실제 GIF · 360×202 · 12fps · 256색

필요는 내가 가장 잘 안다

YTgif는 거창한 제품이 아니라, 한 사람의 하루를 더 매끄럽게 만들려고 시작한 도구입니다. 현장에서 겪은 불편을 그냥 넘기지 않고, 내게 맞는 사용성으로 직접 풀어낸 결과 — 그게 스톤키즈 Lab이 일하는 방식입니다.
